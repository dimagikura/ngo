# Dimagi Kura Official Website

Official public-facing digital platform and resource hub for **Dimagi Kura**, a youth-led mental health awareness initiative based in Kathmandu Valley, Nepal.

## Tech Stack
- **HTML5**: Semantic, accessible markup.
- **CSS3**: Modern custom properties, flexbox/grid layouts, responsive styling without external frameworks.
- **Vanilla JavaScript**: Modular ES6 scripts for navigation, slideshows, vertical film-roll gallery, resource filtering, and client-side form validation.

## Deployment Instructions
1. Clone or download this repository.
2. Ensure all static assets (images, logos) are placed in `assets/images/`, `assets/icons/`, and `assets/logos/`.
3. Connect the repository to **Netlify** or **GitHub Pages** for instant static hosting with zero build steps required.
